How to test "Safe-Heap: Malloc with Canaries"

In the projects folder (/s3k/projects), there are 3 example codes of the implemented features for a our malloc with Canaries

Examples:
-s3k/projects/malloc:
    --In app1/main.c
    --This project exposes some tests of our implementation.
        ---The test include several tests that may be intersting. Out of these:
            ----Test1 checks if the implementation can handle single alloc and free operations in multiple times
            ----Test2 checks that the created canary is randomly placed (run twice)
            ----Test3 checks the limit of 25 malloc obejcts and otherwise return null pointer 
            ----Test4 Shows how use-after-free is detected. Should print "INTEGRITY CHECK FAILED" in the end of this test (program will not finish in this test)
    --To run the program change directory to s3k/projects/malloc folder and run "make clean && make qemu"

-s3k/projects/malloc_fragmentation:
    --A test that calls malloc and free many times, showing that
        the fragmentation is not too bad, and that malloc works.
    --To run the program, change to the folder, and run make clean && make qemu
    --The program should say that all 100 tests succeded and print out a representation
        of the heap metadata after all the tests.

-s3k/projects/deploying-malloc-example: 
    --A quick example of using our malloc as replacement for the real malloc
    --To run the program change directory to s3k/projects/deploying-malloc-example folder and run "make clean && make qemu"

-s3k/project/malloc_exploit
    --Purpose of this test is to show how the trap handler prevents modifying a the canary metadata
        section that shouldn't be accessable. Preventing modifications to the canary_table.
    --A define can be changed to either try to write to the metadata, or to just perform a buffer overflow.
        If the writing to the metadata, the program is expected to stop running and print:
        "Illigal Canary Write Attempted From". If it is not used, it is expected to detect the buffer overflow
        and print: "Canary check failed! Buffer overflow detected in app1's canary table".
        The define is called WRITE_TO_CANARY_METADATA and is located in app1's main.c file.
    --To run the program just runthe following inside the malloc_exploit folder:
        "make clean && make qemu"
